# VELORE – ระบบร้านค้าออนไลน์น้ำหอมนำเข้า (PHP + MySQL) เวอร์ชัน 2

## ติดตั้งบน XAMPP (Windows)

1. เปิด **XAMPP Control Panel** แล้ว Start **Apache** และ **MySQL**
2. วางโฟลเดอร์ทั้งหมดไว้ที่ `C:\xampp\htdocs\VELORE`
3. เลือกอย่างใดอย่างหนึ่ง
   - **ติดตั้งใหม่ (ยังไม่มีข้อมูล):** เปิด http://localhost/VELORE/install.php
   - **มีฐานข้อมูล VELORE จากเวอร์ชันเก่าอยู่แล้ว:** เปิด http://localhost/VELORE/upgrade.php (ข้อมูลสินค้า/ออเดอร์เดิมไม่หาย)
   - หรือ phpMyAdmin → Import → `database.sql`
4. **ลบ `install.php` และ `upgrade.php` ทิ้งหลังใช้เสร็จ**
5. หน้าร้าน: http://localhost/VELORE/  ·  หลังร้าน: http://localhost/VELORE/admin/login.php
   - ผู้ใช้เริ่มต้น `admin` / `admin123` → ไปที่เมนู **เปลี่ยนรหัสผ่าน** ทันที

## ตั้งค่า
แก้ที่ `includes/config.php` : `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASS`, `BASE_URL` (ชื่อโฟลเดอร์ใน htdocs), `LOW_STOCK` (จำนวนที่ถือว่าสินค้าใกล้หมด ค่าเริ่มต้น 5)
ถ้าใช้ `install.php` / `upgrade.php` ที่ MySQL มีรหัสผ่านหรือพอร์ตต่างจากค่าเริ่มต้น ให้แก้ค่าบนสุดของ `install.php` ด้วย

## ฐานข้อมูล
`categories`, `products` (มี `category_id`), `orders`, `order_items`, `stock_logs`, `admins`

## รูปสินค้า
**โฟลเดอร์เก็บรูป:** `C:\xampp\htdocs\VELORE\uploads\`  (นามสกุล jpg, jpeg, png, webp, gif, svg, avif)

**ตั้งชื่อไฟล์ (ใช้อักษรอังกฤษ/ตัวเลข ไม่เว้นวรรค) อย่างใดอย่างหนึ่ง**
- `product-ID.jpg` เช่น `product-1.jpg`, `product-2.png` (ดู ID ได้ที่แอดมิน → สินค้า หรือ แอดมิน → รูปภาพ)
- ชื่อสินค้าตัวพิมพ์เล็กคั่นด้วย `-` เช่น `sauvage-eau-de-parfum.jpg`, `terre-d-hermes.png`

**ผูกรูปกับสินค้า:** ใส่ไฟล์แล้วเข้า แอดมิน → **รูปภาพ** → กด "เชื่อมรูปอัตโนมัติ" (ติ๊ก "แทนที่รูปเดิม" ถ้าต้องการให้ทับรูปตัวอย่าง) หรือเลือกไฟล์ให้สินค้าทีละรายการ
หรือจะอัปโหลดผ่าน แอดมิน → สินค้า → แก้ไข ก็ได้เช่นเดิม

**หลักการแสดงผล:** ใช้ไฟล์ที่ชื่อในฐานข้อมูลก่อน (ถ้ามีไฟล์อยู่จริง) → ถ้าไม่มี ใช้ไฟล์ที่ชื่อตรงกฎด้านบน → ถ้าไม่มีเลย แสดงรูปสำรอง `assets/placeholder.svg`
รูปที่โหลดไม่ได้ (ไฟล์เสีย) จะถูกเปลี่ยนเป็นรูปสำรองอัตโนมัติ ระบบไม่ลบไฟล์หรือสินค้าเดิม
`BASE_URL` ตรวจจากตำแหน่งโฟลเดอร์ให้อัตโนมัติ ไม่ต้องแก้แม้เปลี่ยนชื่อโฟลเดอร์

## หมายเหตุ
- ยอดขายในรายงาน/Dashboard นับเฉพาะออเดอร์สถานะ ชำระแล้ว / จัดส่งแล้ว / สำเร็จ
- ทุกการเปลี่ยนสต็อก (ขาย, ยกเลิกออเดอร์, ปรับเอง, แก้ในหน้าแก้ไขสินค้า) บันทึกลง `stock_logs`
- ยกเลิกออเดอร์ → คืนสต็อกอัตโนมัติ  เปิดกลับ → ตัดสต็อกอีกครั้ง (ถ้าของไม่พอจะเปิดไม่ได้)
- ล็อกอินผิด 5 ครั้งถูกล็อก 5 นาที, ไม่ใช้งาน 2 ชั่วโมงออกจากระบบอัตโนมัติ
- ก่อนขึ้นเว็บจริง: เปลี่ยนรหัสผ่านแอดมิน ใช้ HTTPS ตั้งรหัสผ่าน MySQL และลบส่วนแสดงรายละเอียด error ใน `config.php`

## ระบบสมาชิก (ลูกค้า)

**หน้าบ้าน:** `register.php` สมัคร · `login.php` เข้าสู่ระบบ · `logout.php` · `account.php` แก้ไขโปรไฟล์ (ชื่อ/เบอร์/ที่อยู่) และเปลี่ยนรหัสผ่าน · `checkout.php` สั่งซื้อ (ต้องล็อกอิน) · `order_success.php` · `orders.php` ประวัติการสั่งซื้อ · `order.php?id=` ติดตามสถานะ

**การชำระเงิน:** โอนผ่านบัญชีธนาคาร (สถานะเริ่มต้น "รอชำระเงิน") หรือเก็บเงินปลายทาง (เริ่มที่ "กำลังเตรียมสินค้า")
แก้เลขบัญชีจริงที่ `includes/config.php` → `BANK_NAME`, `BANK_ACCOUNT_NO`, `BANK_ACCOUNT_NAME`

**สถานะออเดอร์:** รอชำระเงิน → ชำระเงินแล้ว → กำลังเตรียมสินค้า → จัดส่งแล้ว → สำเร็จ (และ ยกเลิก ซึ่งคืนสต็อกอัตโนมัติ)

**หลังบ้าน:** ออเดอร์จากสมาชิกเข้า `admin/orders.php` อัตโนมัติ (มีป้าย "สมาชิก" และช่องวิธีชำระเงิน) · `admin/order_view.php` เปลี่ยนสถานะได้ · `admin/customers.php` ดูรายชื่อสมาชิก จำนวนออเดอร์ ยอดซื้อ

**อัปเกรดฐานข้อมูลเดิม:** เปิด `http://localhost/velore/upgrade.php` หนึ่งครั้ง (เพิ่มตาราง customers, คอลัมน์ customer_id / payment_method, สถานะ preparing โดยไม่ลบข้อมูลเดิม) แล้วลบไฟล์ upgrade.php ออก
ออเดอร์เก่าที่สั่งก่อนมีระบบสมาชิกยังอยู่ครบ (customer_id เป็น NULL)

## รายการตรวจเว็บไซต์ (Scorecard) – สิ่งที่เพิ่มให้

- **ข้อมูลติดต่อ:** `contact.php` + footer — แก้เบอร์/อีเมล/ที่อยู่/LINE ที่ `includes/config.php` (`SHOP_PHONE`, `SHOP_EMAIL`, `SHOP_ADDRESS`, `SHOP_LINE`, `SHOP_HOURS`)
- **Privacy Policy (PDPA):** `privacy.php` (ลิงก์ใน footer)
- **Analytics:** ใส่ `GA_MEASUREMENT_ID` (เช่น `G-XXXXXXXXXX`) ใน `includes/config.php` ระบบจะฝังโค้ด Google Analytics ทุกหน้าหน้าบ้านให้
- **หน้า 404:** `404.php` + `.htaccess` (ถ้าโฟลเดอร์ไม่ได้ชื่อ `velore` ให้แก้ path ใน `ErrorDocument`)
- **Meta description:** แยกเฉพาะแต่ละหน้า (สินค้า/หมวดหมู่/ค้นหา/ตะกร้า ฯลฯ)
- **สินค้า 12 รายการ, หมวดหมู่ 5 หมวด** (เพิ่ม Citrus) — ฐานข้อมูลเดิมให้เปิด `upgrade.php` หนึ่งครั้ง ระบบเพิ่มเฉพาะที่ยังไม่มี ไม่แตะข้อมูลเดิม
- **HTTPS:** ต้องตั้งที่เซิร์ฟเวอร์ (XAMPP: เปิด SSL ใน Apache `httpd-ssl.conf` หรือขึ้นโฮสต์ที่มี SSL) — โค้ดทำแทนไม่ได้

## เพิ่มเติม: สองภาษา / ภาษี / ปักหมุด / สลิป / ขนส่ง

- **สองภาษา (ไทย/EN):** ปุ่ม "ไทย | EN" มุมขวาบนของหน้าร้าน แก้ข้อความทั้งหมดที่ `includes/lang.php` (ตาราง `'key' => ['ไทย', 'English']`) คำอธิบายสินค้าอังกฤษอยู่ในคอลัมน์ `products.description_en` (ว่าง = แสดงภาษาไทย) หลังบ้านเป็นภาษาไทยเสมอ
- **ภาษี/ค่าส่ง:** ตั้งที่ `includes/config.php` → `VAT_RATE` (7), `VAT_INCLUDED` (false = บวกภาษีเพิ่มจากราคาสินค้า, true = ราคารวมภาษีแล้ว), `FREE_SHIPPING_MIN` (3000, ซื้อครบส่งฟรีทุกขนส่ง) ยอดที่ชำระ = ราคาสินค้า + ภาษี + ค่าส่ง บันทึกแยกในออเดอร์ (`subtotal`, `vat_amount`, `shipping_fee`) ออเดอร์เก่าไม่เปลี่ยนตัวเลข
- **ปักหมุดแผนที่:** หน้าชำระเงินและหน้า "ข้อมูลของฉัน" ใช้ OpenStreetMap (ฟรี ไม่ต้องมี API key แต่ต้องต่ออินเทอร์เน็ต) แอดมินเห็นลิงก์พิกัดในหน้าออเดอร์
- **แนบสลิป:** ลูกค้าแนบได้ที่หน้าสั่งซื้อสำเร็จ/หน้าติดตามออเดอร์ (JPG/PNG/WEBP ไม่เกิน 5 MB) ไฟล์เก็บใน `uploads/slips/` แบบปิดไม่ให้เปิดตรง ดูได้เฉพาะเจ้าของออเดอร์และแอดมิน แอดมินตรวจแล้วเปลี่ยนสถานะเป็น "ชำระเงินแล้ว" เอง
- **ขนส่งพันธมิตร (จำลอง):** ลูกค้าเลือก Flash Express / SPX Express (Shopee) / Kerry / ไปรษณีย์ไทย ตอนสั่งซื้อ (ค่าส่งและระยะเวลาต่างกัน คิดรวมในยอดทันที) เมื่อแอดมินกด "จัดส่งแล้ว" ระบบ "จองขนส่ง" ให้อัตโนมัติ ออกเลขพัสดุ และสถานะพัสดุเดินหน้าเองเป็นขั้น ๆ (รับพัสดุ → ศูนย์คัดแยก → ขนส่ง → ศูนย์ปลายทาง → นำจ่าย → ส่งสำเร็จ) พอถึงขั้นสุดท้ายออเดอร์เปลี่ยนเป็น "สำเร็จ" เอง ลูกค้าติดตามได้ที่หน้าออเดอร์และ `track.php` ทั้งหมดเป็นระบบจำลองเพื่อสาธิต ไม่ได้เชื่อมขนส่งจริง
  - ความเร็วของการจำลอง: `COURIER_STEP_MINUTES` ใน `includes/config.php` (ตอนนี้ 2 นาที/ขั้น ใช้สาธิตให้ครูดูสดได้ ตั้ง 240 = ทุก 4 ชั่วโมง สมจริงกว่า)
  - แก้รายชื่อขนส่ง/ค่าส่ง/ระยะเวลาที่ `shipping_companies()` ใน `includes/config.php`
- **อัปเดตฐานข้อมูลเดิม:** เปิด `upgrade.php` หนึ่งครั้ง (เพิ่มคอลัมน์ใหม่ ไม่ลบข้อมูล)

## QR พร้อมเพย์ (ลูกค้าสแกนจ่าย)

- หน้าสั่งซื้อสำเร็จและหน้าออเดอร์ (แบบโอนเงิน ที่ยังรอชำระ) แสดง QR พร้อมเพย์ที่ใส่ยอดเงินของออเดอร์ให้อัตโนมัติ ลูกค้าเปิดแอปธนาคาร → สแกน → ยืนยัน แล้วแนบสลิปต่อได้ทันที
- ตั้งเบอร์โทร (10 หลัก) หรือเลขบัตรประชาชน/ผู้เสียภาษี (13 หลัก) ของร้านที่ `includes/config.php` → `PROMPTPAY_ID` และชื่อที่แสดง `PROMPTPAY_NAME` (ค่าเริ่มต้นเป็นเบอร์สมมติ ต้องเปลี่ยนเป็นของจริงถึงจะสแกนจ่ายได้) เว้นว่าง = ไม่แสดง QR
- ตัวสร้าง QR เขียนไว้ในโปรเจกต์ (`includes/qr.php`) ไม่ต้องใช้อินเทอร์เน็ตหรือไลบรารีภายนอก
